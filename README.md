# Calendar

Month calendar with events, public holidays (country picker), and red Saturdays/Sundays. Light, dark and auto theme. No libraries, no account.
Events are saved in your browser (localStorage), so they stay on the device you use.

## Run
Open `index.html`, or run `npx serve .`

## Deploy
Repo → Settings → Pages → Deploy from branch → `main` / root.

## Holidays
India is built in (fixed-date holidays for any year, festival dates for 2026-2027; moon-based dates can shift by a day).
Other countries load live from [Nager.Date](https://date.nager.at), no key needed.
